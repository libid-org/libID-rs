libid_transcript

Module ranges 

Source
Expand description

TLS transcript parsing and byte-range helpers for selective disclosure.

All functions operate on raw transcript bytes (sent / recv) and return Range<usize> offsets into them. The revealed slices become Merkle leaves that on-chain verifiers check, so every helper here fails closed: a range that cannot be located contiguously in the RAW transcript (e.g. a JSON snippet split across a chunk boundary) yields None rather than a mis-resolved leaf.
