pub fn sign_message(key: &SigningKey, message: &[u8]) -> Result<Vec<u8>>
Expand description

Sign a message with a secp256k1 private key (Ethereum-style: keccak256 prehash). Returns a 65-byte signature: r (32) || s (32) || v (1), with the raw 0/1 recovery byte (no EVM offset — see sign_eth_claim for the 27/28 convention).
